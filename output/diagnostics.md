# Diagnostics -- T1: air_distance_km & drive_time_min

Standalone table `output/t1_distance.rds` / `.csv`: **250,000** rows (one per original order), columns `OrderNumber`, `air_distance_km`, `drive_time_min`. **Not merged** into the transaction table.
- Distances computed once on **21,846** unique (customer PLZ, store PLZ) pairs, then attached by pair.
- Locatable rows: **240,874**. Unlocatable rows set to sentinel `-999`: **9,126** (3.65%).

## Method
- Centroids: PLZ polygons projected to EPSG:25832 (ETRS89/UTM32N), area centroid, back to WGS84.
- Store location = centroid of the store's modal customer PLZ (ties -> smallest PLZ), from valid rows.
- `air_distance_km` = Haversine (Earth radius 6371.0088 km); `drive_time_min` = ORS Matrix (driving-car).
